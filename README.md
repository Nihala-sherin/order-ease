# OrderEase

An AI-powered order management system designed to help small home-based sellers manage customer orders received through WhatsApp.

## Problem

Small sellers often manage customer orders manually through WhatsApp conversations, making it difficult to track order details, delivery dates, and pending payments.

## Planned Features

- Extract order details from exported WhatsApp chats using AI.
- Review, edit, and manage extracted orders.
- Track upcoming deliveries and pending payments.

## Tech Stack

- Java
- Spring Boot
- Spring Data JPA
- MySQL
- React
- Gemini API
